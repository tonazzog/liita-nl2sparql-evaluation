# Question Sets

All three files are JSON objects with a `test_cases` array; each case has an `id`, the question(s), a gold `sparql` query and its `answer_variables`. Checksums are in `SHA256SUMS`.

## `final_test_set.json` (86 questions, ids 4001–4086)

The final test set, byte-identical to the frozen file used in the thesis (SHA-256 `4e63a354…`). Its internal `name` field still reads "draft, not frozen": it was written when the set was assembled and was not edited afterwards, so as not to change the hash.

| Field | Content |
|---|---|
| `id` | identifier |
| `cell`, `group` | cell of the grid (e.g. `C6-02`) and group (`S`, `C1`–`C13`, `M`) |
| `resources`, `ops` | resources and elementary operations involved |
| `register` | `tecnico` (technical) or `studente` (student) |
| `nl_en`, `nl_it` | English and Italian formulations (the final evaluation used `nl_en`) |
| `sparql` | gold query |
| `answer_variables` | `primary` (answer columns), `secondary`, `aggregates`, `numeric`, `equivalents` (`{iri_var: literal_var}`) |
| `gold_rows` | number of gold rows when the set was frozen |
| `seed`, `params` | sampled seed and parameters of the cell |

`final_test_set.pre_sentix.json` is the version before the Sentix correction (12 questions; see `docs/METHODOLOGY.md`), kept for the sensitivity analysis.

## `development_set.json` (71 questions, ids 3001–3071)

Written as a held-out set for the original systems and then used as the development set. Fields include `category`, `structure` (`simple` or a composition operator), `patterns`, `nl_en`, `nl_variants`, `sparql`, `answer_variables`, `gold_rows`, `review_status` and `note`. Generated by `construction/development_set/draft.py` (with `draft_extra.py`).

## `regression_set.json` (100 questions, ids 2000–2151)

The test set of the first evaluation, with the canonical gold queries shared by the three systems (identical to `data/test_dataset.json` in each system at the tag). Fields: `category`, `nl_en`, `patterns`, `sparql`, `answer_variables`, `expected_components`.
